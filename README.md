# Lab : 8 Operator Overloading

## Objective

Implement and test several overloaded operators in C++ by completing a Rational number class. This lab gives practice with operator overloading, class design, and basic exception handling.

## Instructions

Using the file Rational.h as a guide, Implement the following overloaded operators:

operator+, operator-, operator*, operator/

operator=

operator double() const

operator<< (as a friend function)
